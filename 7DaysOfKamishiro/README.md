## 1. 概要説明
【タイトル】カミシロ村の7日間 

【ジャンル】2D育成RPGノベルゲーム

【難易度】簡単  

【プレイ時間】30分～1時間30分 程度  

【推奨年齢】全年齢  

unity1weekで制作した2D育成RPGノベルゲームです。  

神の依り代になってしまう幼馴染の少女を助けるべく、期日の7日後までにたくさんの思い出を作ります。  

毎日1日の行動力が尽きるまで、おでかけ/しらべる/鍛える/休む の4つの選択肢から行動を選び、少女の運命を決めます。  

## 2. 制作意図
学外のデザイナーさんとチームを組んで制作を行うということで、デザインを前面に出していけるゲームを製作しようということでノベルゲームを製作してみようということになりました。  

ただ文字を送るだけではつまらないので選択肢として育成ゲーム風に行動を選べるようにする機能と、RPG風の戦闘要素を取り入れて作りました。  

## 3. 制作期間
2026年 7/26~8/2 (1週間)  

## 4. 担当箇所
- シナリオ制作
- 会話システム
- 戦闘システム (2人で制作)
- 少女の表情差分の変更や背景の変更、行動フェーズでの少女の移動など細かなエフェクト
- UI

## 6. 遊び方・操作方法

### 遊び方:
基本的にはテキストを読んでいきます。  

また、毎日自由に行動ができる行動フェーズがあります。  

ここでは行動力というものを使い、お出かけや儀式について調べることができます。その日の行動力が0になると自動的に次の日に移ります。

### 操作方法:  
左クリック/Enterキー：進める  

Esc：メニューを開く  

右上の▶ボタン：手動/自動/早送りの切り替え  

右上の≡ボタン：メニュー画面を開く

## 7. 意識したこと・工夫点
デザイナーさんの描いたキャラクターたちが魅力的に見えるように、ただ立ち絵を表示するだけではなく、怒った時のモーションであったり、行動フェーズ中に少女が画面上を左右に揺れながら動くようにしたり、視覚的な部分をこだわりました。

## 8. 改善点・反省点
今回、初めてノベルゲームを制作したため、シナリオの文章量を適切に見積もることができず、想定よりも長いシナリオとなってしまいました。  

また、シナリオの読み込みにはノードシステムを採用しましたが、文章量が増えるにつれてノードへの入力作業が膨大になり、手作業だけでは対応が難しくなり、AIを利用して文章の入力作業を補助する必要が生じました。  

シナリオのように大量の文章データを扱う場合には、ノード形式で直接入力するのではなく、CSVなどの外部ファイルから会話データを読み込む仕組みにした方が、実装や修正を効率化できたと考えています。
